## 📝 使用示例

### 示例1：内科医生年度报告

**输入**：
```
项目名称: 张医生内科年度报告平台
前端框架: React + TypeScript
可视化库: ECharts
后端框架: Node.js + Express
数据库: PostgreSQL
特殊需求: 需要支持慢性病管理数据可视化
```

**输出**：
完整的内科医生年度报告平台，包括患者复诊率分析、慢性病管理效果、用药统计等专业功能。

特殊需求: 重点展示手术成功率和并发症统计

**输出**：
专业的外科手术数据可视化平台，包含手术类型分析、成功率趋势、并发症监控等核心功能。

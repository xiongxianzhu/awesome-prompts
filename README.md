## 📖 简介

这是一个精心策划的AI提示词集合，涵盖了编程、内容创作、生产力、商业等多个领域。无论你是AI爱好者、开发者还是创作者，这里都有适合你的提示词。

## ✨ 特色

- 🎯 **高质量**：每个提示词都经过精心挑选和测试
- 🗂️ **分类清晰**：按用途和领域进行系统分类
- 🔄 **持续更新**：定期添加新的优质提示词
- 🤝 **社区驱动**：欢迎社区贡献和分享
- 📝 **详细文档**：每个提示词都有使用说明和示例

## 📁 目录结构

```
awesome-prompts/
├── prompts/              # 提示词分类目录
│   ├── development/      # 开发相关（项目生成、编程辅助等）
│   ├── content/          # 内容创作（写作、营销、社交媒体等）
│   ├── productivity/     # 生产力工具（任务管理、学习等）
│   ├── creative/         # 创意相关（艺术、故事、游戏等）
│   └── business/         # 商业应用（战略、分析、沟通等）
├── templates/            # 提示词模板
├── featured/             # 精选提示词
├── docs/                 # 详细文档
└── scripts/              # 实用工具
```

# 🌐 国际化指南

## 📖 简介

Awesome Prompts 项目致力于为全球用户提供多语言支持，让不同语言背景的用户都能方便地使用高质量的提示词资源。

## 🎯 目标语言

我们目前支持以下语言：

| 语言 | 语言代码 | README文件 | 状态 |
|------|----------|------------|------|
| 🇨🇳 简体中文 | zh-CN | [README.md](../../README.md) | ✅ 完成 |
| 🇺🇸 English | en-US | [README.en.md](../../README.en.md) | ✅ 完成 |
| 🇯🇵 日本語 | ja-JP | README.ja.md | 🔄 进行中 |
| 🇰🇷 한국어 | ko-KR | README.ko.md | 🔄 进行中 |

## 🤝 如何贡献翻译

### 1. 翻译新的README版本

#### 步骤 1: 创建文件
根据语言代码创建新的README文件，命名格式：`README.{语言代码}.md`

#### 步骤 2: 翻译内容
将以下内容翻译为目标语言：

- 项目标题和描述
- 功能特色
- 目录结构
- 快速开始指南
- 统计信息
- 精选提示词介绍
- 技术栈说明
- 学习资源
- 贡献指南链接
- 许可证信息

#### 步骤 3: 保持格式一致
确保翻译后的文件保持与原版相同的：
- Markdown格式结构
- 链接路径
- 图片和徽章
- 代码块格式

### 2. 翻译提示词内容

除了README文件，我们也欢迎翻译提示词本身：

#### 提示词文件翻译
- 在提示词文件中添加多语言版本
- 保持原有的英文版本作为基准
- 使用注释或章节分隔不同语言版本

#### 示例格式：
```markdown
# English Version

## Original Prompt
```
English prompt content here...
```

## 🇨🇳 中文版本

## 中文提示词
```
中文提示词内容...
```
```

### 3. 更新语言导航

添加新语言后，请更新所有README文件中的语言导航表格：

```markdown
## 🌐 语言选择

| 🇨🇳 简体中文 | 🇺🇸 English | 🇯🇵 日本語 | 🇰🇷 한국语 | 🇩🇪 Deutsch |
|-------------|------------|----------|----------|------------|
| [简体中文](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [한국어](./README.ko.md) | [Deutsch](./README.de.md) |
```

## 📝 翻译指南

### 翻译原则

#### 1. 保持原意准确
- 确保技术术语翻译准确
- 保持专业性和一致性
- 避免过度意译导致信息偏差

#### 2. 适应本地化需求
- 考虑目标语言的表达习惯
- 使用当地用户熟悉的术语和例子
- 调整文化相关的内容

#### 3. 格式规范
- 保持Markdown格式完整
- 链接和图片路径保持一致
- 表格和列表格式正确

### 技术术语翻译对照表

| 英文 | 中文 | 日文 | 韩文 |
|------|------|------|------|
| Prompt | 提示词 | プロンプト | 프롬프트 |
| AI Model | AI模型 | AIモデル | AI 모델 |
| Machine Learning | 机器学习 | 機械学習 | 기계 학습 |
| Code Generation | 代码生成 | コード生成 | 코드 생성 |
| Natural Language Processing | 自然语言处理 | 自然言語処理 | 자연어 처리 |
| Artificial Intelligence | 人工智能 | 人工知能 | 인공 지능 |

### 常用表达翻译

#### 项目介绍
- "A curated collection of" → "精心策划的"
- "High-quality" → "高质量的"
- "Welcome contributions" → "欢迎贡献"

#### 功能描述
- "Easy to use" → "易于使用"
- "Well-documented" → "文档完善"
- "Community driven" → "社区驱动"

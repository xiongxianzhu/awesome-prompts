## 📖 什么是提示词？

提示词（Prompt）是你向AI模型（如ChatGPT、Claude等）输入的指令或问题。好的提示词能够：

- ✨ 提高AI响应的质量和准确性
- 🎯 明确指定你想要的输出格式
- 💡 激发AI的创造力和分析能力
- ⚡ 节省时间和提高工作效率

## 🛠️ 实用技巧

### 💡 提示词优化技巧

#### 1. 明确具体
❌ 不好的例子：

```text
帮我写个程序
```

✅ 好的例子：

```text
帮我用Python写一个命令行工具，用于批量重命名文件，功能包括：
1. 支持正则表达式匹配
2. 提供预览功能
3. 支持撤销操作
请包含完整的错误处理和使用说明
```

#### 2. 提供上下文
❌ 不好的例子：

```text
解释这个错误
```

✅ 好的例子：

```text
我在运行以下Python代码时遇到了错误：

```python
import pandas as pd
data = pd.read_csv('data.csv')
print(data.column_name)  # 这里报错
```

错误信息：AttributeError: 'DataFrame' object has no attribute 'column_name'

请帮我分析错误原因并提供解决方案。
```

#### 3. 指定输出格式
✅ 好的例子：

```text
请用以下JSON格式返回分析结果：

{
  "summary": "简要总结",
  "key_points": ["要点1", "要点2"],
  "recommendations": ["建议1", "建议2"],
  "confidence_score": 0.95
}
```

## 🤔 常见问题

### Q: 如何选择合适的AI模型？
**A**:
- **ChatGPT**: 适合通用对话和编程任务
- **Claude**: 擅长长文本处理和创意写作
- **Gemini**: 在多模态和实时信息方面有优势

### Q: 提示词没有效果怎么办？
**A**:
1. 检查提示词是否完整
2. 确认AI模型是否支持
3. 尝试调整参数和措辞
4. 查看示例对比使用方法

### Q: 可以修改提示词吗？
**A**: 当然可以！鼓励根据你的具体需求进行调整和优化。
